# Chaitanya Krishna — AI/ML Engineer Portfolio

Production-grade portfolio with AI chat assistant powered by Groq.

## Local Setup

```bash
# 1. Install Node dependencies
npm install

# 2. Add your video file
cp your-intro-video.mp4 public/intro.mp4

# 3. Start dev server
npm run dev

# Open http://localhost:5173
```

## Build for Production

```bash
npm run build
# Output is in /dist
```
